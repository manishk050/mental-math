# Speed Math

A fast, keyboard-first mental math practice website.

## Features

- Choose one or multiple operations: addition, subtraction, multiplication, division
- Easy, Medium, and Hard difficulty
- Exactly 10 questions per round
- Elapsed-time timer
- Incorrect answers do not advance the round
- Type answers from the keyboard without clicking an input field

## Deployment

The repository includes a GitHub Pages workflow at `.github/workflows/pages.yml`. Configure the repository's Pages source to **GitHub Actions** once, then pushes to `main` deploy automatically.
