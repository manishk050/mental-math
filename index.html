How it works

Keyboard-first answers

Start typing immediately. You never need to click an answer box. Use Backspace to edit and Enter to check.

Choose one or several operations

Select a single operation for focused drills or several operations for mixed mental math practice.

Three difficulty levels

Easy uses smaller numbers, Medium expands the range, and Hard uses larger arithmetic. Division questions are generated with whole-number answers.

FAQ

How many questions are in each round?

Exactly 10 questions.

Does a wrong answer count as a completed question?

No. The current question remains active until the correct answer is entered.

Do I need an account?

No. The game runs directly in your browser.
